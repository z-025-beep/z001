# 设计与技术规范

## 视觉规范
- 风格：正式思政课件风，简洁、庄重、适合投屏展示。
- 配色：浅绿山地、深蓝河流、浅色平地，整体保持自然和信息清晰。
- 字体：统一使用中文无衬线/系统字体，保持稳定易读。
- 图层：地图为主，信息卡为辅，避免过度装饰。

## 交互规范
- 所有导航按钮需有清晰状态反馈。
- 热点点击统一打开弹窗，并允许关闭回到地图。
- 分站切换必须更新顶部标题、右侧提示和进度条。
- 闯关模块仅处理界面与跳转逻辑，允许后续接题库。

## 代码规范
- HTML负责页面结构。
- CSS负责视觉样式和布局。
- JavaScript负责状态切换、弹窗控制和简单交互逻辑。
- 所有文件保持无依赖、可直接浏览器打开，避免复杂构建流程。

## 内容规范
- 当前阶段先保留占位区域。
- 如需补充真实图片、视频和文案，可在对应位置替换。
- 每个热点都保留统一数据结构，便于后续接入真实内容。
